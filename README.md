# 오늘한컷

우리 가족 4명(짱토리, 쑤, 이니짱, 토리오빠)이 하루에 사진 한 장씩 올리고, 다음 날 낮 12시까지 투표해서 1위를 정하는 웹앱입니다. 매주 1위 사진은 짱토리가 A5 오일파스텔로 그립니다. 가족은 claude.ai 계정 없이 초대 링크만으로 들어옵니다.

## 규칙 (모두 한국 시간)

- 사진은 하루 1장이며 밤 12시까지 올리거나 바꿀 수 있습니다. 내 사진을 올려야 가족의 오늘 사진이 보입니다.
- 어제 사진의 투표는 오늘 0시부터 낮 12시까지 열립니다. 누가 올린 사진인지 모르게(이름 숨김, 사람마다 다른 순서) 투표합니다. 내 사진에는 투표할 수 없고, 1인 1표이며 마감 전까지 바꿀 수 있습니다.
- 낮 12시에 누구 사진인지와 4명의 전체 순위가 공개됩니다. 표가 같으면 같은 순위입니다. 결과 탭에는 이번 주 누적 득표 순위도 나옵니다.
- 주간 1위는 일요일 사진의 투표가 끝나는 월요일 낮 12시에 정해집니다. 짱토리만 그림을 올릴 수 있습니다.
- 💬 오늘톡: 짱토리 → 쑤 → 이니짱 → 토리오빠 순서로 하루씩 돌아가며 한 명이 질문하고, 나머지는 밤 12시까지 한 줄로 답합니다. 내가 답해야 가족의 답이 보입니다. 낮 12시까지 질문이 없으면 누구나 추천 질문을 올릴 수 있습니다.
- 사진은 올릴 때 1600px JPEG로 다시 저장되므로 사진 속 위치 정보가 지워집니다.

## 처음 한 번만 하는 설정 (보스님)

### 1. Supabase 프로젝트 만들기

1. supabase.com 에서 무료(Free) 요금제로 새 프로젝트를 만듭니다. 지역은 Seoul(Northeast Asia)을 고릅니다.
2. **Authentication → Sign In / Providers** 에서 **Allow anonymous sign-ins**(익명 로그인)를 켜고 저장합니다.
3. **SQL Editor → New query** 에 `supabase/schema.sql` 전체를 붙여넣습니다.
4. 붙여넣은 화면에서만 맨 아래 `CHANGE-ME-family-code` 를 가족만 아는 영문·숫자 10자 이상 코드로 바꾸고 **Run** 을 누릅니다.
   - 저장소의 `schema.sql` 파일에는 진짜 코드를 적지 마세요. 저장소는 공개입니다.
   - 코드를 바꾸고 싶으면 마지막 `insert ... on conflict` 문장만 새 코드로 다시 실행하면 됩니다.
   - 2026년 5월 30일 이후 만든 Supabase 프로젝트는 새 표를 앱에 자동으로 열어주지 않아서, schema.sql 안에 그 허락(grant) 문장도 넣어 두었습니다. 예전 schema.sql 을 이미 실행했다면 `supabase/grants.sql` 만 한 번 더 실행하면 됩니다.
5. **Project Settings → API Keys**(또는 API)에서 **Project URL** 과 **anon public 키**(또는 publishable 키)를 복사해 `config.js` 에 넣습니다.
   - **service_role / secret 키와 데이터베이스 비밀번호는 절대 넣지 마세요.**

6. 오늘톡을 쓰려면 SQL Editor 에서 `supabase/talk.sql` 도 한 번 실행합니다(가족 코드를 넣는 곳은 없습니다).

### 2. GitHub Pages 켜기

1. 공개 저장소 `today-shot` 에 이 폴더의 파일을 올립니다.
2. 저장소 **Settings → Pages → Build and deployment** 에서 Source 를 **Deploy from a branch**, 브랜치를 **main / (root)** 로 정하고 저장합니다.
3. 1~2분 뒤 `https://parapioo.github.io/today-shot/` 가 열리면 준비 완료입니다.

### 3. 가족 초대

가족 단톡방에 아래 링크를 보냅니다. `가족코드` 자리에 4번에서 정한 코드를 넣습니다.

```
https://parapioo.github.io/today-shot/#join=가족코드
```

- 처음 한 번 열면 "나는 누구인가요?" 화면에서 이름을 고릅니다. 다음부터는 그냥 `https://parapioo.github.io/today-shot/` 로 열립니다.
- 휴대폰 브라우저의 **홈 화면에 추가**를 하면 앱처럼 쓸 수 있습니다.
- 폰을 바꾸거나 브라우저 기록을 지웠다면 초대 링크로 다시 열어 원래 이름을 고르면 됩니다. 그 이름의 사진과 투표 기록은 그대로 남아 있습니다.

## 알아둘 점

- Supabase 무료 요금제는 1주일 동안 아무도 쓰지 않으면 프로젝트가 일시 정지됩니다. 그때는 Supabase 대시보드에서 다시 켜면 됩니다(Restore).
- 무료 저장 공간은 1GB입니다. 사진 1장이 약 0.3~0.6MB이므로, 하루 4장이면 대략 1~2년 정도 쓸 수 있다고 추정합니다(실제 크기는 사진마다 다릅니다).
- 초대 링크를 아는 사람은 누구나 가족 이름 자리에 들어올 수 있습니다. 링크가 밖으로 퍼졌다면 가족 코드를 바꾸고 새 링크를 보내세요.
- "내 사진을 올려야 가족 사진이 보인다"는 규칙은 화면에서만 가립니다. 가족끼리 쓰는 앱이라 이 정도로 충분하다고 보았습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 틀과 디자인 |
| `app.js` | 초대 링크, 이름 고르기, 오늘·투표·결과·갤러리 4개 화면 |
| `config.js` | Supabase 주소와 공개 키 (보스님이 채움) |
| `supabase/schema.sql` | 표, 보안 규칙, 사진 저장소 설정 |
| `supabase/grants.sql` | 앱이 표에 접근하도록 허락 (schema.sql 에 이미 포함) |
| `supabase/talk.sql` | 오늘톡 표와 보안 규칙 |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면에 추가할 때 쓰는 이름과 아이콘 |
